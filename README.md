**🎬 FilmVault — Movie Explorer App**

FilmVault is a React-based movie exploration app where users can browse trending movies, view detailed information, and manage their personal Watchlist.
It uses TMDB API for real-time movie data and features search, sort, and filter options with a clean UI built using Tailwind CSS.
***


**🚀 Live Demo**
🔗 https://filmvault-app.netlify.app/

***

**🛠️ Tech Stack**
Frontend

⚛️ React.js
🎨 Tailwind CSS
🌐 TMDB API
🔄 React Hooks
🧭 React Router
📦 Local Storage

**⚙️ Installation & Setup**

git clone https://github.com/NisargaCode/filmVault.git
cd filmVault
npm install
npm run dev
***

**📡 API Usage (TMDB)**

FilmVault uses TMDB’s Trending Movies API:
https://api.themoviedb.org/3/trending/movie/week?api_key=YOUR_KEY
